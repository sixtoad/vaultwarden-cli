# Linux verification

Default, all-features and no-default-features suites each exited **0**: 965 reported passes, 0 failures, 15 ignored tests and 13 benchmark smoke successes. Of those reported passes, **71 live-Vaultwarden tests returned early** because the live environment was absent; each profile therefore exercised 894 passing tests. All three documentation-test commands exited 0 with no documentation tests discovered.

Cargo check, formatting, strict all-target/all-feature Clippy and `git diff --check` passed. Real mapped-UID noninteractive agent transport passed (1 test), the real Firefox regression passed with no unexpected diagnostics, and real systemd supervision passed (2 tests). The ignored harnesses in ordinary suites are not represented as automatically exercised; these dedicated regressions are recorded separately.

**All 11 scoped Rust security mutants compiled and failed runtime assertions.** There were no survivors, invalid mutations, skips or timeouts. The guards covered password verification, mutual TLS, authority generation, exact review, the final ticket deadline, ticket device binding, ticket consumption, password rate limiting, enrolled certificate identity, closed JSON fields and private identity-file modes. This was a targeted semantic campaign, not an exhaustive mutation run. After mutation restoration, all 10 Rust source hashes matched and the final companion run exited 0: **15 passed, 0 failed, 1 ignored** manual acceptance fixture.

The first default run exposed an unsafe-file test assumption about umask; the test now explicitly creates its intended public mode. It also hit an existing launcher timeout, which passed using the CI concurrency of four test threads. An initial browser run reported the provider unavailable; an isolated rerun passed. Concurrent build/test load exhausting the bounded fixture lifetime is a possible cause, not a proven diagnosis. Initial Clippy failures were resolved by naming ignored error bindings. All original failure logs remain in the archive.

Final Clippy, mutations and restored-source tests used the final hashes.
